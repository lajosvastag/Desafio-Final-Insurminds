# Direção visual — Sala de Subscrição

- **Tema**: visual inspirado em mesas de análise de risco, com tipografia editorial e contraste sóbrio.
- **Movimento**: leitura de dossiê técnico; cada bloco responde a uma pergunta de subscrição.
- **Princípios**: densidade controlada, evidência antes de opinião, alertas visíveis e linguagem direta.
- **Paleta**: azul petróleo `#172A3A` como base, marfim `#F6F2EA` para superfícies, dourado `#D49A31` como sinal de decisão, vermelho queimado `#B65745` para risco.
- **Layout**: coluna de navegação curta, área principal em duas colunas para comparar documentos e uma faixa de sinais críticos.
- **Assinatura**: marca Curié Edge e selo “IA + regras auditáveis”.
- **Interação**: ações progressivas — carregar, analisar, comparar; estados de loading e erro são claros.
- **Tipografia**: IBM Plex Sans para interface, Georgia para títulos de leitura jurídica.
- **Tom**: rigoroso, acessível e transparente sobre o uso de IA.
